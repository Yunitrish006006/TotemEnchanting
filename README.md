# TotemEnchanting

TotemEnchanting owns enchanting-power behavior and Enchanting Table changes.
It depends on TotemCore and Fabric API, not on another feature module.

`0.1.0` is the Java 25 extraction artifact. It owns the weighted Chiseled
Bookshelf power helper and the Enchanting Table/Menu Mixins while preserving
Minecraft's existing enchantment identifiers. DeadRecall remains the live
owner until standalone validation and the reversible cutover are complete.

See [EXTRACTION.md](EXTRACTION.md) for ownership and validation rules.
